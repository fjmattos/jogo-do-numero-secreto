# Jogo do Número Secreto

Este é um jogo simples, mas divertido, desenvolvido em Javascript, onde o jogador precisa adivinhar um número secreto gerado aleatoriamente. O jogo dá dicas se o número chutado é maior ou menor que o secreto, e conta o número de tentativas até o jogador acertar.

## Como Jogar

1.  Clone este repositório para sua máquina.
2.  Abra o arquivo `index.html` em seu navegador.
3.  Digite um número entre 1 e 10 no campo indicado.
4.  Clique no botão "Chutar" para verificar seu palpite.
5.  O jogo dirá se o número secreto é maior ou menor que o seu chute.
6.  Tente adivinhar o número secreto com o menor número de tentativas possível!

## Funcionalidades

*   Geração de número secreto aleatório.
*   Dicas se o número chutado é maior ou menor.
*   Contagem de tentativas.
*   Mensagem de parabéns ao acertar, com o número de tentativas.
*   Botão para reiniciar o jogo.
*   Interface de usuário amigável.
*   Voz responsiva que narra as mensagens do jogo (utiliza a biblioteca `responsiveVoice`).

## Tecnologias Utilizadas

*   HTML
*   CSS
*   Javascript
*   Biblioteca `responsiveVoice` (para a funcionalidade de voz)

## Como Executar o Jogo

1.  Clone o repositório: `git clone https://github.com/fjmattos/jogo-do-numero-secreto`
2.  Abra o arquivo `index.html` em seu navegador.
